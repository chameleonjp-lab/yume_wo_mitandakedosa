# 共通 UI とスコア連携の変更

この変更はレビュー用です。マージ・GitHub Pages 公開・実機受入の完了を意味しません。

## 変更点
- ホームのランキング名は任意。空欄で遊べます。参加名は開始時に固定し、途中の名前変更を進行中の結果に混ぜません。IME 変換中の Enter では開始しません。
- ホームと結果画面に X 共有を用意。投稿文には参加名を含めず、2 つのハッシュタグとゲーム URL を含めます。投稿確定はプレイヤーが X 上で行い、ポップアップ失敗時はコピーの代替画面を表示します。
- 15 言語、各 71 キーの UI。言語変更は表示だけを更新し、ゲーム開始やスコア再送信を行いません。
- 効果音の ON/OFF と音量を保存。初期値は ON・0.3、保存済みの OFF・0 を維持します。音声初期化は利用者の操作に応じて試み、失敗してもゲームを続けます。
- 結果を端末に保存して読み戻せます。前の記録を控えに残せない場合は上書きを中止します。読み戻しはスコアを再送信せず、ランキング読み取りだけを行います。
- ランキングの読み取り状態とスコア送信状態を分離。読み取りの再試行はスコアを送信しません。両ランキング RPC に `p_limit: 30` を指定し、表示も最大 30 行に制限します。返された正の安全な整数の `rank_no` と同点順位を維持し、不明な順位は「—」で表示します。不明なスコアを 0 点に変換しません。

## スコア応答の検証範囲

既存の通常 `submit_score` を使い、1 要素の配列と次の 8 キーを検証します。

`accepted`, `result_normalized_name`, `result_display_name`, `result_first_score`, `result_best_score`, `result_play_count`, `is_first_play`, `is_new_best`

開始時の参加名と送信前に固定した今回スコアに対する形・名前・得点・フラグの整合を確認した場合だけ、送信済み表示に進みます。不明な応答や通信エラーは成功扱いにせず、自動で再送しません。古いプレイの応答で新しい結果を描画しません。

**この検証は参加者本人性、同名参加者の分離、永続化、冪等性の証明ではありません。** 既存 API は名前ベースで、プレイ ID による重複排除を提供していません。結果を確認できない場合でもサーバー側で受理済みの可能性があり、無条件再送はできません。端末保存もサーバー受領の証拠ではありません。

ランキング読取側は 6 列全体の厳密なスキーマ検証を行うものではありません。従来の表示得点／raw 得点の別名参照は残っており、数値フォーマッターは有限小数も受け付けます。今回の読取回帰確認は実際の `rank_no`・`first_score`・`best_score` を持つ行と、欠損値・不正値の表示を対象としています。

## 維持するゲーム仕様

初期 60 秒、衛星の +4 秒／見逃し −3 秒、フレーム差分上限 0.05 秒を維持します。毎秒 +100、青被弾 −500、赤被弾 −3000／見逃し −2000、🍶取得 +1500／見逃し −3000、赤破壊自体は加点なしです。ゲーム名・ID・保存キー・符号付き整数の降順スコアを変更していません。39 の元ゲーム関数をハッシュ照合し、表示メッセージの意味キー化 3 箇所だけを明示的な比較例外としています。

## ローカル確認

依存追加はありません。Node.js の標準ライブラリだけで実行できます。各テストはファイルの静的解析、純粋なヘルパー、または限定的に取り出した関数をローカルの代替 DOM/RPC/音声と組み合わせます。ゲーム全体の実行、実通信、実スコア送信、ブラウザ起動は行いません。

```sh
for test in tests/*.cjs; do node "$test" || exit 1; done
```

確認対象：言語キーと数値の整合、名前の固定、共有文、保存失敗、コピー代替、音声制御、ゲーム計算の保持、応答検証、古い応答の排除、ランキングの表示・読取専用再試行・30 行制限、JavaScript 構文と DOM 参照。
